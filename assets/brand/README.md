# OpenReading brand assets

Use the navy badge for app icons and avatars. Use the standalone blue mark over your own background.

| Variant | SVG source | PNG exports |
| --- | --- | --- |
| Navy badge with transparent corners | [`icon.svg`](icon.svg) | `icon-{size}.png` |
| Blue mark with a fully transparent background | [`icon-transparent.svg`](icon-transparent.svg) | `icon-transparent-{size}.png` |

Both variants include square PNGs at 32, 64, 128, 256, 512, 1024, 2048, and 4096 pixels.
The PNGs contain real alpha transparency. A white SVG preview is the viewer's canvas, not part of the artwork.

Use SVG for scalable layouts and PNG when an application requires a raster image.
The 4096-pixel exports provide the highest raster resolution. Every size is rendered directly from its SVG source.

The palette is navy `#0c2c40` and blue `#51b8e5`. Preserve the square canvas, clear space, and original proportions.
